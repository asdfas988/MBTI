# 内在剧场

一个基于 Astro 的中文心理学静态内容站，面向 MBTI、精神分析、人格心理学和精神动力学写作。

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物会输出到 `dist/`。

## Cloudflare Pages 部署

连接 GitHub 仓库后使用：

```text
Build command: npm run build
Build output directory: dist
```

## 内容目录

```text
src/content/articles   长文章
src/content/concepts   心理概念词典
src/content/topics     专题合集
src/content/mbti       MBTI 类型页面
src/content/cases      角色与案例分析
```
